# Security Policy

## Supported version

Only the current `main` deployment is maintained. Brave Buddy is still a browser-local prototype and is not approved for public launch.

## Report a vulnerability

Use GitHub private vulnerability reporting: open this repository's **Security** tab and select **Report a vulnerability**. Do not open a public issue for a security weakness and do not include child information, legal advice, credentials, or incident data in a report.

If **Report a vulnerability** is not available, stop and ask the repository owner to enable it. The project has not approved a fallback email or service, so this file does not invent one.

Include the affected URL or revision, impact, reproduction steps, and a suggested fix when known. Do not test with real child data or attack the production service.

## Response status

Dung is the initial security and incident owner. A backup owner, response target, disclosure timeline, independent penetration test, and final security approval remain open in `docs/LAUNCH_READINESS_REGISTER.md`. This policy is a safe intake path, not a promise of response time or a security certification.
